## Overview
Built a simulated industrial control system environment using the Purdue Model.

## Features
- Segmented OT zones (L0-L3)
- VLAN + firewall isolation
- Modbus/TCP & OPC UA traffic analysis
- Zeek / Suricata IDS monitoring
- Wireshark packet inspection

## Tech Stack
VirtualBox, pfSense, Kali Linux, Ubuntu, Zeek, Suricata, Python

## Key Findings
- Plaintext Modbus commands observable
- Unauthorized lateral movement blocked by segmentation
- IDS signatures detected suspicious scans
